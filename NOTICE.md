# Public Portfolio Subset

This repository is a deliberately incomplete and sanitized portfolio representation of a private commercial desktop application.

It excludes production business logic, WhatsApp extraction internals, report-generation implementation, email-delivery implementation, authentication tokens, employee records, attendance ledgers, browser profiles, private tests, packaging secrets, generated reports, installers, and executable binaries.

All names, dates, statuses, and metrics visible in the UI preview are fictional. No license is granted for commercial reuse or redistribution of the omitted system design.
